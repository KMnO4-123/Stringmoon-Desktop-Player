================================================================================
一、概述与目标
================================================================================

构建一款桌面端音乐播放器（Windows 优先），核心目标：

- 高性能：C++20 自研引擎，实时安全，低延迟（WASAPI 独占起步 3ms 周期）
- 低负载：播放中内存 ≤100MB、CPU <1%（基础播放）；空闲 ≤90MB、<0.5%
- 多功能：专业输出（DSD/DoP、ASIO、VST3 宿主）、曲库智能、场景自动化、
  平台桥接；功能分层、插件化，不启用时零开销
- 不臃肿：刻意不做清单（§3.9）长期有效
- 高级审美：澄明之境（§5），湿玻璃、三层深度、光晕指针、水滴进度条、
  歌词浸入；动效有物理依据，稳定 60fps（p95 <16.7ms）
- 可交付：含测试、打包、自动更新、签名、崩溃报告的完整工程闭环（§9）

口径说明（相对早期版本的修正，写入验收标准）：
- 内存：Slint 桌面应用基线 50–80MB + 引擎 10–20MB，"≤40/60MB" 不可达；
  坚持 60MB 需走软件渲染路线 → 由阶段 0 实测决策（§10）。
- 延迟：应用侧（引擎提交到驱动缓冲）≤6ms；含 DAC/USB 链路 8–14ms。
- 术语：主引擎与 UI 同进程（§4.1）；"IPC/共享内存"仅用于插件进程。

二、选型与许可证
================================================================================

2.1 主选型结论
--------------------------------------------------------------------------------
C++20 自研引擎 + Slint UI + 类型安全 C ABI 桥接。
兼顾专业音频能力、低延迟、低内存与高级审美；
VST3/ASIO 许可风险已于 2025-10 消除（见 2.2）。

2.2 许可证重大事实（2025-10 核实，直接影响可交付性）
--------------------------------------------------------------------------------
① VST3 SDK 3.8+ 已转 MIT：无需签约/费用，闭源宿主直接集成；VST2 不在内。
② ASIO SDK 2.3.4 起双许可 GPLv3 / 专有：闭源发布走专有许可；遵守商标规范。
③ Slint 三许可：GPLv3 / 免版税 / 商业。闭源桌面走免版税许可，
   唯一义务是署名（AboutSlint 组件或"关于"页声明）；嵌入式除外。
④ MQA：资产归 Lenbrook，授权体系复杂 → 本方案不做 MQA 渲染，
   MQA 文件按基础层 PCM（44.1/48kHz）正常播放。相关工时删除。
⑤ librespot（MIT，v0.8 活跃）：代码可闭源集成，但 Spotify 服务属 ToS 范畴，
   接入做风险隔离（§12）。

三、引擎架构
================================================================================

3.1 分层总览
--------------------------------------------------------------------------------
┌─────────────────────────────────────────────────────────────┐
│ UI 层（Slint，瘦客户端：渲染/交互/订阅，不做音频处理）        │
└──────────────────────┬──────────────────────────────────────┘
                       │ C ABI + 环形缓冲 + 快照（同进程）
┌──────────────────────▼──────────────────────────────────────┐
│ 桥接层：类型安全接口、命令封装、事件分发、稳定 API 契约      │
└──────────────────────┬──────────────────────────────────────┘
                       │ 无锁 SPSC 环形缓冲 / 消息队列
┌──────────────────────▼──────────────────────────────────────┐
│ C++20 引擎（唯一音频权威，闭环完成）                         │
│ ┌────────┐ ┌────────┐ ┌──────────┐ ┌──────────┐            │
│ │ 解码层 │ │ DSP 层 │ │ 混音/输出│ │ 元数据   │            │
│ │ FFmpeg │ │VST3/EQ │ │WASAPI/   │ │ TagLib   │            │
│ │ SoXR   │ │DSD/RG  │ │ASIO      │ │ CUE/封面 │            │
│ └────────┘ └────────┘ └──────────┘ └──────────┘            │
│ 实时约束：无锁、无分配、无系统调用（RTSan 在 CI 验证）       │
└──────────────────────┬──────────────────────────────────────┘
                       │ 原生音频 API
┌──────────────────────▼──────────────────────────────────────┐
│ 平台适配层：Windows（WASAPI 共享/独占、ASIO、DSD/DoP）       │
│ 后续：macOS CoreAudio / Linux ALSA                           │
└─────────────────────────────────────────────────────────────┘
原则：引擎是唯一音频权威；UI 只发命令、订状态；桥接层屏蔽复杂性，
     音频样本绝不穿越桥接层（只传命令与状态元数据）。

3.2 UI 层选型（Slint）
--------------------------------------------------------------------------------
- 声明式 DSL 编译为机器码，运行时无解释器；C++ API 直接集成，无跨语言桥接。
- 内存可控（50–80MB 级）；AccessKit 桌面无障碍开箱即用；gettext 国际化。
- 版本锁定 1.18.x；桌面渲染默认 femtovg/Skia（GPU），软渲染作为备选。
- 与引擎同进程，通过 C ABI + 环形缓冲 + 快照交互（§4）。

3.3 线程模型与实时安全
--------------------------------------------------------------------------------
三线程（v1.0 原模型保留并强化）：

| 线程        | 职责                    | 约束                     |
| 渲染(RT)    | 音频回调、DSP、混音输出 | 无锁/无分配/无系统调用   |
| 控制        | UI 命令、播放状态机     | 可阻塞；SPSC 下行命令    |
| I/O         | 解码、网络流、元数据    | 可阻塞；SPSC 上行 PCM    |

- MMCSS：渲染线程 AvSetMmThreadCharacteristics("Pro Audio")，退出时还原；
  注册失败降级 HIGHEST 并记日志（不硬扛 TIME_CRITICAL，防饿死系统）。
- 优先级：RT=HIGHEST/执行级；解码= BELOW_NORMAL；扫描=IDLE。
- SPSC 环形缓冲：alignas(64) 防伪共享；索引仅 acquire/release。
- 命令在音频块边界处理，单块最多 32 条，余量顺延（防 UI 洪泛）。
- 背压：RT 消费慢于 IO 生产时反向阻塞解码线程，对齐播放速度。
- 内部格式：float32 planar（DSP 友好）；仅在输出边界交织并做位深转换。
- 欠载恢复：RT 内不写日志（只计数）；连续 3 次 xrun → 缓冲 ×2（上限 50ms）
  并提示；24h 无欠载且开启"激进低延迟"才回缩。
- 设备热插拔：IMMNotificationClient 监听；AUDCLNT_E_DEVICE_INVALIDATED →
  淡出 10ms → 释放流 → 按设备 ID 重开 → 失败回退默认设备 → 淡入 20ms；
  蓝牙自动降级共享模式并加大缓冲；独占被占（会议软件）静默降级共享。

3.4 输出与低延迟策略
--------------------------------------------------------------------------------
- 独占：3ms 周期 ×2 缓冲起步（失败回退设备默认周期并记录）；事件驱动回调。
- 共享：IAudioClient3 查询设备最小周期（GetSharedModeEnginePeriod）×2 起步。
- 采样率：独占按源采样率重开流（bit-perfect），切换间隙 10–20ms 淡出/淡入；
  共享不重开流，源≠设备率时启用 SoXR；同率时 SoXR 断言跳过（零开销）。
- 位深：输出 < 源位深时启用 TPDF dither；bit-perfect 路径禁用。
- 音量：float 域软件音量，一阶 ≈10ms 平滑防 zipper；拖音量提示
  "将退出 bit-perfect"。
- 延迟监控：管线注入探测信号定期测量；口径=应用侧 ≤6ms / 端到端 8–14ms。

3.5 DSP 层
--------------------------------------------------------------------------------
- EQ：10 段 IIR（31.25/62.5/125/250/500/1k/2k/4k/8k/16k Hz，1 倍频程）；
  RBJ peaking，Q 默认 1.41（0.5–4 可调）；±12dB/0.5dB 步进；
  系数 ≈20ms 每样本插值平滑；自动前级或 2ms lookahead 软限幅（二选一）；
  旁路 30ms 交叉淡变。预分配节点，零分配。
- 重采样：SoXR 仅在采样率不一致时激活（缓存重采样器实例）。
- ReplayGain 2.0：libebur128 扫描（整轨+专辑）写库，可选写回标签（先临时
  文件后替换）；播放目标 -18 LUFS（可选 -23/-16/-14）；用 track_peak 做
  防削波（超限衰减至 -0.1dBFS）；模式：关/单曲/专辑，切换 30ms 平滑。
  独立"实时限幅"开关（原 v1.0 动态层），默认关，不与 RG 混淆。
- 变速：signalsmith-stretch（MIT）实现 0.5×–2.0× 变速不变调；独立变调；
  切换 200ms 平滑；预设见 §6.3。
- 交叉淡入淡出引擎与 Gapless 实现细节见 3.8。

3.6 DSD 专章（可施工口径）
--------------------------------------------------------------------------------
① DoP（走 WASAPI 独占）：DSD64→24bit/176.4kHz，DSD128→352.8k，
   DSD256→705.6k；每帧 16bit DSD/通道 + 8bit 标记（0x05/0xFA 交替）。
   铁律：DoP 路径禁止一切 DSP（EQ/重采样/变速/数字音量），否则标记失效。
   DoP 播放时数字音量不可用 → 直通（由 DAC/功放控制）并在 UI 明示。
② Native DSD：Windows 实际依赖 ASIO 驱动暴露 DSD 率（WASAPI 一般不暴露）；
   仅在 ASIO 后端提供，不可用时自动降级 DoP/PCM 并提示。
③ DSD→PCM（开启 DSP 时）：半带 FIR 抽取（参考 dsd2pcm 算法自研，勿链接
   GPL 代码）；自动切换并在播放栏显示 "DSD → PCM" 徽标，可一键切回直通。
④ PCM→DSD 调制输出：噪声整形 ΣΔ（级联 2 阶×3 或 6 阶）；难度高，
   排期最后（Could 级）；验收用逆转换对比（带内 THD+N 达标）。
⑤ 策略：默认直通（DoP/Native）；一旦 EQ/音量衰减激活 → 自动转 PCM 路径。

3.7 VST3 宿主（分阶段，配合 MIT 许可）
--------------------------------------------------------------------------------
- v1：进程内加载 + 崩溃防护（SEH/向量异常捕获）；插件崩溃 → 自动旁路 +
  黑名单 + 提示；扫描器独立进程（首次扫描需用户确认目录）。
- v2：进程外沙箱（共享内存传音频、IPC 传参数、插件 GUI 独立窗口嵌入）。
- 参数：采样点级自动化平滑（20ms 斜坡）；插件延迟（latency samples）
  上报引擎纳入延迟补偿。
- 借鉴 VST3 SDK hosting 示例起步。

3.8 无缝与交叉淡入淡出（实现细节）
--------------------------------------------------------------------------------
- 预解码：下一首完整体常驻缓冲（本地 ≥2s 前导，网络流 ≥8s）。
- Gapless：同专辑（album+album_artist+连续 track_no 且非手动切歌）采样级
  拼接；异采样率先各自重采样到设备率再拼接。
- 交叉：等功率曲线；随机播放 300ms；手动切歌不交叉（5ms 淡出防爆音）；
  尾部渐弱（2s 窗口 RMS 斜率 <-6dB/s）缩短至 150ms；
  尾部硬切（>3dB/s 突降）延长至 500ms。设置中仅一个开关，默认开。

3.9 功能分层与加载策略（完整保留）
--------------------------------------------------------------------------------
Layer 1 基础播放（引擎内置，不可妥协）
- 格式：MP3/AAC/WAV/AIFF/FLAC/ALAC/WavPack；DSD(DSF/DFF/ISO) 可选模块
- 控制：播放/暂停/停止、上下曲、Seek、音量、队列（顺序/单曲/列表/随机）
- 状态推送：100ms 快照（pull 模式，§4.3）
Layer 2 专业音频（引擎核心，始终可用）
- WASAPI 独占/共享、ASIO 可选后端；Native DSD 与 DoP；ReplayGain 2.0；
  10 段 IIR EQ；SoXR
Layer 3 人性化功能（默认内置，轻量）
- 智能曲库（索引/分类/封面/取色）；AI 补全（显式可选、默认关、联网前
  展示 diff）；Gapless；交叉淡入淡出（默认关）；变速不变调；
  全局快捷键与系统媒体控制；迷你模式、桌面歌词；LRC 解析同步
Layer 4 可选扩展（插件化，不启用=零开销）
- VST3 宿主（进程隔离）；频谱可视化（引擎 FFT 可选节点 + UI 插件）；
  Scrobbler（Last.fm/ListenBrainz）；远程控制（HTTP API 插件）；
  音乐平台桥接（协议/API 插件）
刻意不做（长期有效）
- 社交（好友/排行/评论）、沉浸互动（养鱼/3D）、商店/推荐流、
  内置下载器、AI 音效黑盒、MQA 渲染


================================================================================
四、桥接层
================================================================================

4.1 进程模型（决策）
--------------------------------------------------------------------------------
主引擎与 UI 同进程（多线程）；仅 VST3 宿主（v2）与插件扫描器独立进程。
理由：跨进程音频共享内存引入额外抖动，个人播放器收益为负；双进程基线
内存不可接受。UI 崩溃=应用崩溃的风险由崩溃报告兜底（§9.4）。

4.2 通信机制
--------------------------------------------------------------------------------
| 数据              | 方式                | 频率          |
| 控制命令          | 环形缓冲/消息队列   | 低频事件驱动  |
| 播放状态快照      | 三缓冲/seqlock      | 100ms 周期    |
| 频谱/波形         | 共享环（二进制）    | 每帧（按需）  |
| 曲库数据          | SQLite + 封面 LRU   | 按需查询      |
关键：PCM 样本绝不穿越桥接层；频谱节点无消费者时不计算（零开销）。

4.3 接口契约与状态同步
--------------------------------------------------------------------------------
- 稳定 C ABI（extern "C"）：engine_create/destroy/play/pause/seek/get_state/
  set_dsp_param ...（v1.0 原型保留）
- 配置结构带 struct_size + abi_version；不匹配拒绝创建并返回错误码。
- 错误码枚举（OK/ERR_DEVICE/ERR_DECODE/...）；跨 C 边界不抛异常。
- 每函数标注可调用线程；UI 回调经控制线程转发，禁止在 RT 线程回调。
- 字符串全 UTF-8，定长上限与截断规则明确。
- 快照采用 pull 模式：UI 每帧读最新完整快照（三缓冲），引擎只更新不推送；
  内容：当前曲目、精确时间戳、播放状态、队列摘要。

五、UI/UX 设计（澄明之境）

5.1 视觉基底：光、水、空气
--------------------------------------------------------------------------------
色彩：基底深空蓝黑 #0B0C10。三层深度：
  远层(背景)#0B0C10 深海 | 中层(内容)#111318 水面下 | 近层(浮起)#181A21 近水面
强调色：默认封面取色 → 饱和 -15%、明度 60–70%、色相 +5% 蓝偏（如透过水面）；
  该处理由主题令牌参数化（可固定 / 跟随系统色，§5.8）。
材质"湿玻璃"（非毛玻璃）三要素：
  ① 厚度：inset 0 0 0 0.5px rgba(255,255,255,0.08)；顶部 0.1→底部 0.04 渐变
  ② 边缘辉光：左上角 radial 0.06→transparent 70%
  ③ 环境遮蔽：投影 rgba(6,8,18,0.6)，模糊 24–40px，偏移 0–4px（非硬边）
空间：三层过渡为渐变非硬切；弹窗出现时被覆盖中层 brightness(0.95)。

- 响应式：>1200px 信息栏展开；800–1200px 折叠为 72px 窄条（仅封面缩略）；
  <800px 隐藏（播放栏扩展）；过渡 400ms，元素渐隐。
- 导航项非等距：当前项上下间距更大（呼吸焦点）+ 左侧 2px 强调竖线，
  竖线由两端向中间生长（scaleY 0→1，300ms，cubic-bezier(0.34,1.56,0.64,1)）。

5.3 独特功能效果（全部保留，压缩表述）
--------------------------------------------------------------------------------
① 光晕指针：微光晕替代箭头，φ24px，中心 8% 渐隐；移动增亮 12%，
   静止 2s 降 5%；点击收缩 0.8→1（200ms）；pointer-events:none。
② 列表项悬浮：bg rgba(255,255,255,0.03) + 径向阴影；文字 #E8E8EA→#F2F2F4；
   封面 36→40px+0.5px 亮线；200ms；无位移，浮起感靠阴影/亮度。
③ 进度条=水滴滑过玻璃：3px/圆角 1.5；已播强调色+内光晕（inset 0 0 4px
   0.15）；轨道 0.08；播放头 8px+12px 光晕；拖拽 14px/光晕 24px/条高 6px；
   松开 400ms 弹性回缩。
④ 封面=玻璃板：圆角 12+0.5px 内描边；径向高光（30%,20% 处 0.08）；
   倒影（翻转/0.08/模糊 8px/高 40%）；鼠标倾斜 ≤2°，高光跟随。
⑤ 歌词逐行浸入：当前行 translateY(16→0)+opacity+blur(4→0) 500ms；
   18px #F0F0F2；相邻行 15px #4A4A52（blur 0.5px）；旧行上移 12px 溶解
   400ms；行距不等（当前行 24px/相邻 12px）。
⑥ 播放栏光带：悬停 72→80px（300ms）、进度条 3→4px、音量淡入
   （opacity 0→1 + translateX(-8→0)，250ms）、辉光增强；离开 400ms 恢复。
⑦ 队列玻璃板：底部升起（100%→0 + blur 8→0，500ms，
   cubic-bezier(0.16,1,0.3,1)）；主内容 darken 0.95+blur 2px；高度 60%。
⑧ 迷你模式：180×180 圆窗；封面 140px 圆形；2px 进度环；播放时 1.8s/圈
   旋转、暂停 800ms 减速停止；悬停按钮 0.9→1 淡入；整体悬浮水滴投影。
⑨ 搜索光流：展开 200→360px（400ms 弹性）；底部 1px 光线生长 300ms；
   结果逐项浮现（每项延迟 30ms）。

5.7 Slint 实现要点与降级预案（阶段 0 逐项 POC）
--------------------------------------------------------------------------------
- 直接支持：径向/线性渐变、圆角、drop-shadow、发丝内描边、动画与缓动、
  Path 自绘（进度条/搜索光线）、倒影（翻转+透明度）。
- 需降级：歌词 blur 过渡（Slint 无逐元素模糊）→ opacity+位移+字重过渡，
  或仅当前行预渲染模糊位图；"湿玻璃"无 backdrop-filter → 用不透明度+
  渐变模拟（原设计本就依赖渐变，不依赖真模糊）。
- 需 POC：透明/圆形窗口（迷你模式；降级=圆角方形+DWM）、系统光标隐藏
  （降级=保留箭头+光晕叠加）、IME 候选窗定位。
- 观察者：频谱可视化走 OGL 纹理接入（Image::create_from_borrowed_gl_2d_
  rgba_texture）；"3D 微缩房间"降级为 2D 示意图标组。
- 高 DPI：Per-Monitor V2；0.5px 发丝线在 125%/150% 缩放下改用 1 物理像素。
- 无障碍：所有交互元素声明 accessible-role/label/value（AccessKit 自动）；
  键盘全可达，焦点环=1px 强调色+8px 外发光；尊重"减少动态效果"设置。
- i18n：@tr() 全量标记，首发 zh-CN/en；CJK 断行与歌词折行单独测试。
- 主题：完整主题系统见 §5.8（6 预设 + 自定义三档 + 跟随系统）。
- 睡眠场景：不纯黑（保留 2% 亮度底纹，防 OLED 残影与"死机感"）。
- 动效降级：每动效定义低配档 + 总开关；"不运行的视觉效果零 CPU"写成断言。

5.8 主题系统（预设 + 自定义）
--------------------------------------------------------------------------------
架构：主题 = 一组设计令牌（约 35 项）。预设主题=完整令牌集；用户主题=在预设上
做 delta 覆盖。全部颜色/材质经令牌绑定（Slint 全局 Theme 单例），切换即改
令牌值、绑定自动传播 + 600ms 插值；不重建 UI，运行时零额外开销。
令牌分组：color.depth.{far,mid,near}；color.text.{primary,secondary,muted}；
color.accent{ mode: auto|fixed|system, optics: 饱和偏移/明度目标/蓝相偏移 }；
color.semantic.{success,warn,error}；material.{glass 强度,内描边,辉光,投影}；
space.{hairline,radiusScale}；typography.{serif,sans,mono,cjkFallback,scale}；
motion.{intensity,durationScale}；environment.{texture,dimOverlay}

① 预设主题（6 个，均遵循湿玻璃材质公式，只换"底与水色"）
| 主题   | 模式 | 三层深度（远/中/近）           | 强调色处理           | 气质·场景       |
| 澄明   | 暗   | #0B0C10 / #111318 / #181A21    | 封面取色·水色（默认）| 默认·通吃       |
| 深潭   | 暗   | #06080D / #0B0E14 / #12161E    | 封面取色·更深更冷    | 深夜·专注       |
| 琥珀夜 | 暗   | #0E0C09 / #14110D / #1C1813    | 封面取色·暖相偏移    | 夜间暖光环境    |
| 水墨   | 暗   | #0A0A0B / #101011 / #17171A    | 固定朱砂 #C4564B     | 极简·单色一点彩 |
| 晨雾   | 亮   | #EDEFF2 / #F4F5F7 / #FAFBFC    | 封面取色·提纯（冷）  | 日间·冷灰       |
| 宣纸   | 亮   | #F6F3ED / #FBF9F5 / #FFFFFF    | 封面取色·暖调保留    | 日间·暖纸       |
另设"跟随系统"开关（默认关）：随 Windows 浅/深色自动切换 晨雾↔澄明。

② 自定义（三档，渐进暴露）
- 快捷档（设置页 3 控件）：基底（暗/亮/跟随系统）；强调色（封面取色 /
  固定色轮+8 预设色板 / 跟随系统强调色）；玻璃厚度 0.5×–1.5×。
- 进阶档（主题编辑器）：三层深度色逐层拾取（含 HEX）；强调色光学参数
  （贴近封面/柔和/淡雅三档快捷 + 细调）；材质（内描边/辉光/投影浓度）；
  环境（背景纹理：无/极淡有机纹/深空颗粒 + 强度）；排版（字体族 + 中文
  回退链预览、字号阶梯 ±10%）；动效（强度：完整/精简/关闭，全局时长倍率
  0.5×/1×/1.5×）；圆角 0/6/12/16px。
- 高级档（Power User）：主题 JSON 直编（应用内代码视图 + 实时预览）；
  导入/导出 .tetheme（JSON + 元信息 + 微缩预览图）；预设 fork 为
  "我的主题"，一键还原。

③ 交互与动效
- 主题切换"颜料入水"：新主题从播放栏中心径向扩散晕开（800ms，
  cubic-bezier(0.16,1,0.3,1)），颜色 600ms 插值；降级=全屏交叉淡化。
- 每曲强调色流动：auto 模式下强调色随封面变化并套用本主题光学处理
  （同一封面在"澄明"是水色、在"琥珀夜"是暖琥珀）；提供固定开关。
- 主题网格：每主题一张微缩实时界面缩略（列表+播放栏+封面），
  悬停微动效（进度条轻滑）。

④ 质量约束（写入验收）
- 对比度：正文 ≥4.5:1、次要 ≥3:1（WCAG AA）；自定义不足时黄色警示徽标
  （不强制拦截）；语义色配图标冗余（色盲安全）。
- 主题不影响键盘焦点环可见性与"减少动态效果"设置。
- 切换验收：800ms 内完成、60fps、无 UI 重建；连续快速切换 20 次无异常。

6.1 聆听核心（高频 · 低认知负荷）
--------------------------------------------------------------------------------
- 智能续听：记录精确位置/队列/循环/音量/EQ/输出设备；同时段打开静默预加载
  下一首；无弹窗；曲名从模糊到清晰（blur→0，600ms）。
- 智能交叉淡入淡出：规则见 §3.8；设置中仅一个开关，默认开。
- 音量均衡：ReplayGain 静态层（§3.5）+ 独立实时限幅开关（默认关）；
  音量图标旁小波形图标，悬停显示当前增益。
- 睡眠定时器：设"30 分钟后停止"→ 检测当前曲目何时结束，落曲中则等播完；
  停止前 30s 音量平滑衰减至 0（cubic-bezier(0.4,0,1,1) 先慢后快）；
  月亮图标呼吸（0.6→1.0→0.6，4s）。

6.2 曲库智能（中频 · 中认知负荷）
--------------------------------------------------------------------------------
- 音乐地图：二维平面 X=年代(1960–2026) Y=能量(安静–激烈)；光点=曲目
  （色取封面主色，大小∝播放次数）；悬停放大 2×、周围排斥；点击播放并
  平滑缩放；框选建临时列表；滚轮以鼠标为中心缩放；播放轨迹 24h 淡出。
  能量值来源：libebur128 响度 + 自研谱通量（避免引入 AGPL 分析库）。
- 智能去重：指纹（Chromaprint）+标签相似度+时长偏差+比特率差异；
  通知式"发现 N 组重复"；堆叠卡片展示匹配度/差异；逐组保留或一键
  "保留最高音质"。
- 元数据批量编辑：正则替换/标签映射/格式标准化/封面嵌入/重命名；
  编辑前"原值→新值"预览表；执行进度用播放栏上方光条。
- 曲库健康检查：缺失/损坏/缺标签/低质量/孤立文件分类卡片；
  展开详情与"修复/忽略"；修复完成后卡片向中心溶解（500ms）。

6.3 聆听体验（中频 · 低认知负荷）
--------------------------------------------------------------------------------
- 聆听房间（空间音频模拟）：录音室/客厅/音乐厅/俱乐部四预设（混响+声场+
  低频策略）→ 自研轻量卷积/早期反射处理（零第三方 GPL 依赖）。
- 歌词实验室：偏移校准（[ ] 微调 ±0.1s 存库）；直接编辑 LRC 实时预览；
  双语对照；罗马音行；双击进编辑模式（细光标+微调按钮）。
- 播放速度与音高：变速 0.5×–2.0× + 独立变调；预设：播客 1.2×/有声书 1.5×/
  学习 0.75×（均保持音调）、练习 0.5×（降 1 八度）；切换 200ms 平滑；
  仪表盘式速度图标。

6.4 场景与自动化（低频 · 高认知负荷）
--------------------------------------------------------------------------------
- 场景模式：专注（无歌词封面、纯列表、EQ 平直）/ 休闲（封面+歌词、EQ 暖、
  客厅空间）/ 派对（队列+低频增强+交叉 500ms）/ 睡眠（极低亮度、无动画、
  定时 30min、音量衰减）；顶栏菱形场景图标；微缩界面预览；
  切换全设置 600ms 过渡（EQ 曲线形变）。
- 智能播放列表：规则组合 AND/OR 可嵌套；实时自动维护；规则构建器
  （左字段右画布，拖拽成条件块，光线连接）。
- 快捷键自定义：全局/窗口/模式三级作用域；键盘可视化点击分配；
  已分配亮起、未分配暗淡、冲突红色脉冲。

6.5 系统集成（低频 · 低认知负荷）
--------------------------------------------------------------------------------
- 系统媒体控制：Windows SMTC（后续 macOS Now Playing / Linux MPRIS）。
- 音频设备自动切换：插耳机→切输出+暂停+500ms 后恢复；拔耳机→暂停+切默认
  设备+不自动恢复；切换时音量图标短暂变形为设备图标（500ms）。
- 文件关联与拖放：拖入窗口播放；队列内拖拽排序（让位动画）；
  拖到播放栏=替换当前队列。安装版写 HKCU 关联，卸载可保留/清理可选。

play_history(track_id, played_at, ms_played)
themes(id, name, kind[preset|custom], base_id, tokens_json, created_at, updated_at)
   -- 主题令牌集（§5.8）；当前主题 id 与"跟随系统"开关存于应用设置
images(hash, src_w, src_h, cache_paths_json)  -- 多尺寸 40/56/96/300/600
scan_state(folder_id, cursor, state, error)   -- 断点续扫
schema_version + 顺序迁移脚本；升级前自动备份 DB。

7.3 扫描管线
--------------------------------------------------------------------------------
- 首扫：IDLE 优先级，目录遍历，每 200 条批事务；10k 曲目目标 <5min。
- 增量：ReadDirectoryChangesW + 2s 去抖；(path,size,mtime) 判脏；
  移动/重命名用指纹兜底。
- 重任务（指纹/响度/波形峰值）：统一后台队列（可暂停、进度上报，
  复用"播放栏上方光条" UI）。

7.4 搜索与持久化
--------------------------------------------------------------------------------
- FTS5 + trigram 分词（中文子串匹配）；输入去抖 120ms；拼音首字母列为
  Could 级。
- playstate.json：原子写（临时文件+rename），每 5s+关键事件+退出时；
  损坏回退 .bak。内容=曲目/位置/队列/循环/音量/EQ/输出设备。

| 场景                     | 目标                        | 备注               |

| 播放中（独占无 DSP）     | ≤100MB / <1%                | 列表浏览场景       |

| 应用侧延迟（独占）       | ≤6ms（周期3ms×2）           | 端到端 8–14ms      |
| 音频稳定性               | 30min 压力 0 xrun；长播     | 独占最小缓冲       |
|                          | <1 xrun/10h                 |                    |
| 启动到发声               | <1s（本地文件）             |                    |
| Seek 响应                | UI <50ms / 声回 <150ms      |                    |
| 曲库 10k                 | 首屏 <600ms；首扫 <5min     | 滚动无卡顿         |
| 动效                     | p95 <16.7ms                 | 开发机构建断言     |

九、工程化（测试 / CI / 打包 / 安全）
================================================================================

9.1 测试
--------------------------------------------------------------------------------
- 单元（Catch2/doctest）：DSP 黄金测试（标准 WAV→EQ/重采样/增益→对比，
  频响 ±0.1dB）；RG 与 loudgain 对齐 ±0.05dB；解析器（LRC/CUE/M3U/标签）
  含中文与损坏样本。
- 实时安全：Clang RTSan（-fsanitize=realtime + [[clang::nonblocking]]）纳入
  CI——RT 路径出现 malloc/锁/系统调用即红；TSan（桥接）ASan/UBSan（debug）。
- 集成：30min 独占最小缓冲压力播放=0 xrun 断言；设备矩阵（板载/USB DAC/
  蓝牙 × 44.1–384kHz × DSD64–256 支持范围内）。
- 延迟测量工具：输出 chirp + WASAPI loopback + 互相关；发布前手动跑并记录。
- UI：Slint testing backend（可访问性树断言+快照）；动效帧时间 p95 断言；
  预设主题对比度自动校验（WCAG AA 断言）。
- 模糊测试：LRC/CUE/M3U/标签解析器 libFuzzer 整夜跑。

9.2 CI/CD
--------------------------------------------------------------------------------
- MSVC 主 + clang-cl 辅（RTSan）；CMake Presets + vcpkg manifest 锁依赖；
  clang-format 强制 + clang-tidy（performance/readability/cert 子集）。
- 流水线：构建→单测→RTSan→打包（portable zip + Inno Setup）→signtool
  签名（带时间戳）→生成 appcast.xml→发布。两阶段 appcast 替代灰度。

9.3 打包 / 更新 / 安装
--------------------------------------------------------------------------------
- 安装版：Inno Setup，per-user 免管理员；文件关联写 HKCU；卸载默认保留
  曲库/设置（可选清理）；便携版（portable.ini，数据随程序目录）；MSIX 后续。
- 更新：WinSparkle（appcast+签名校验，密钥离线保管）；更新前自动备份 DB。
- 托盘：Shell_NotifyIcon 自实现；关闭默认最小化到托盘（可改为直接退出）；
  托盘菜单含播放控制。
- 首启向导三步：音频后端（独占/共享/自动）→ 添加音乐文件夹 → 平台桥接
  开关（默认关）。

9.4 崩溃 / 日志 / 隐私
--------------------------------------------------------------------------------
- Crashpad 或 sentry-native；本地 dump 默认保留，上传可选（展示发送摘要）；
  CI 归档符号并上传符号服务器。
- 日志环形缓冲+异步写（2MB×3 滚动）；音频诊断段（xrun/缓冲史/设备变更史）
  单独文件便于反馈。
- 隐私：默认零遥测；设置内"网络活动"页可查全部请求；全局"离线模式"开关。

9.5 安全清单
--------------------------------------------------------------------------------
- 本地 HTTP/API 代理：仅 127.0.0.1 + 每会话随机 token + 默认关闭 CORS。
- 凭证：DPAPI（CryptProtectData，用户级）加密；OAuth=PKCE+loopback 随机端口。
- 更新通道：HTTPS + 签名双保险。插件扫描：独立进程+用户确认+黑名单。
- 解析器边界：M3U/CUE/LRC 按不可信输入处理（长度/嵌套上限）。

10.2 主线阶段（修订版）
--------------------------------------------------------------------------------
阶段 1 MVP 播放内核（6–8 周）：引擎（WASAPI/解码/Gapless/命令快照）+
  Slint 基础 UI（三区/列表/播放栏）+ SQLite 曲库（扫描/搜索/封面）
  验收：10k 流畅；独占 30min 0 xrun；内存达标；启动到发声 <1s
阶段 2 体验完善（4–6 周）：歌词/快捷键/SMTC/托盘/智能续听/睡眠定时器/
  迷你模式/拖放关联/主题（预设+切换+跟随系统）
  验收：动效 p95 <16.7ms；系统媒体面板同步正确
阶段 3 专业音频（4–6 周）：ASIO/EQ/RG/SoXR/DSD(DoP+转 PCM 路径)/热插拔
  验收：DSP 黄金测试通过；DSD 直通↔转换切换无爆音；延迟实测入报告
阶段 4 工程化收口（2–3 周）：打包/便携/更新/签名/崩溃/无障碍/i18n
  验收：旧版自动更新成功；签名通过 SmartScreen 检查
阶段 5 扩展（持续，按 MoSCoW）：Subsonic Provider→去重→音乐地图→VST3→
  PCM→DSD 调制→主题编辑器与导入导出→更多 Provider

10.3 MoSCoW 砍功能清单（对抗范围蔓延）
--------------------------------------------------------------------------------
Must ：播放/曲库/歌词/WASAPI/EQ/RG/快捷键/SMTC/打包更新/主题（预设+切换+跟随系统）
Should：ASIO、智能去重、音乐地图、迷你模式、睡眠定时器、场景模式、主题编辑器
Could ：VST3、DSD 调制输出、平台桥接、聆听房间、智能播放列表、主题导入导出（.tetheme）
Won't ：社交、商店、下载器、MQA 渲染、3D/粒子、AI 黑盒调音

10.4 时间现实性
--------------------------------------------------------------------------------
阶段 0–1 到可用 MVP ≈2–3 个月；到"体面 v1.0"（含阶段 2–4）≈6–9 个月；
全范围 ≈12 个月+（单人全职估算）。以阶段门禁管理：每阶段末按验收标准
决定继续/砍功能/延期。三人团队（引擎/UI/数据）可压缩约 40%，
前提是桥接 ABI 与 Schema 先行冻结。

附录 A  关键常量
================================================================================
- 独占缓冲 3ms×2 起步（≥50ms 上限，自适应 ×2）；共享=设备最小周期×2；
  蓝牙 ≥20ms
- 预解码本地 ≥2s/流 ≥8s；交叉 150/300/500ms；切歌淡出 5ms
- 快照 100ms（pull）；频谱 30fps 按需
- EQ 10 段 31.25–16k；RBJ；Q 1.41；±12dB/0.5dB；平滑 20ms；旁路 30ms
- RG：-18 LUFS（备选 -23/-16/-14）；防削波 -0.1dBFS
- Dither：输出<源位深时 TPDF；bit-perfect 禁用
- DoP：DSD64→176.4k / DSD128→352.8k / DSD256→705.6k；24bit；0x05/0xFA
- 文件监控去抖 2s；扫描批 200 条；日志 2MB×3；封面临时尺寸 40/56/96/300/600
- 音量平滑 10ms；搜索去抖 120ms
- 主题：令牌 ≈35 项；切换插值 600ms / 颜料扩散 800ms；正文对比度 ≥4.5:1
