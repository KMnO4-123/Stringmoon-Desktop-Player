| **F7** | ⭐ **`realignSegmentsToText`：只信边界，不信文本** | 契约：`(boundaries, text) => string[] \| null`。<br>⭐ **输出 = 原文的切片数组，拼接必然等于原文（by construction）**。<br>**为什么**：模型只会"分割点对、空白归一化错"（尾空格丢、全角折叠、双空格合并）→ 按 join 比对会**因一行外观差异废掉整首歌**。<br>**三种 `null`**：①非空白字符对不上 ②消费完仍有剩余 ③收尾 trim 非空。<br>**上层按行隔离**（单行 null 只让该行回落默认切分），**但批量导入路径是整批抛错**（不允许静默部分导入） |

> ⚠️ **F7 的适用条件**：我方**不用 LLM 分词**（自用不该依赖外部服务）。
> **但它对任何"外部来源给的分段"都适用** —— 包括将来若接 AMLL 或其他分词器。

## 3. 你要遵守的红线（**违反即返工**）

| # | 红线 | 依据 |
|---|---|---|
| **1** | **音频样本绝不穿越通道** | CONTRACT §3 铁律 2 |
| **2** | **不动 `engine/`** | 同工作区协作纪律 |
| **3** | ⭐⭐ **监测不算 DSP** | `dspModules` 的语义是「**有东西在改样本**」。**监测只读 → 不进 `dspModules`，`outputPerfect` 仍可为 true**<br>⚠️ **若 C2 因为"开了频谱"就熄灭 BP，用户会以为自己失去了 bit-perfect——而实际没有** |
| **4** | ⭐ **日志绝不含 token / cookie 明文** | CONTRACT §5、SPEC §9.4。**多渠道后风险上升** |
| **5** | ⭐ **不引入全局常驻单例** | Web 上是纯内存负担，且与 331MB 的既有问题叠加 |
| **6** | ⚠️ **大面积模糊不要逐帧 `backdrop-filter`** | **Folia #605**：Canvas + 全屏 `backdrop-blur-xl` 逐帧重绘 → **GPU/风扇/INP 864ms**<br>**小面积 + 背后静态 → 用；全屏 + 背后动画 → 改成一次性烘焙的模糊图** |
| **7** | ⭐ **后台/失焦即停 rAF 与 WebGL** | **Folia 目前不暂停**（#538/#539 是 **enhancement 请求**）——**你的要求是"低负载"，这件事必须第一天做对** |
| **8** | ⭐ **不 monkey-patch `window.requestAnimationFrame`** | Folia 做了（203 行全局限流器），**且自己标为实验性并警告可能出问题**。**把限帧做成显式调度参数** |
