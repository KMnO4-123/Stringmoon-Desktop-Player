# Stringmoon 截图（v0.4.0）

本目录是公众版 README 与文档引用的界面截图。全部截自 **Stringmoon 0.4.0**（Windows x64，
1280×800 逻辑窗口，2 倍 DPR 采集后等比缩到宽 1600，PNG 调色板优化）。

| 文件 | 对应界面 | 说明 |
| --- | --- | --- |
| `main-library.png` | 我的曲库 | 曲库工作区：左侧导航、曲目列表与歌单/艺术家分栏、底部播放栏 |
| `discover.png` | 发现 | 发现页（QQ 音乐源）：每日 30 首、刷歌雷达、排行榜入口；未登录态 |
| `audio-console-eq.png` | 音频 → 音频控制中心 · EQ | 频响曲线 + 十段参数均衡器（频点/增益/Q 全可见） |
| `audio-console-output.png` | 音频 → 音频控制中心 · 输出 | 输出模式（自动/独占/共享）、采样率列表、解码能力矩阵 |
| `settings-output.png` | 设置 → 播放 | 播放体验、输出与规格（最高 352.8 kHz）、探测结果 |
| `lyrics.png` | 沉浸播放 | 黑胶封面 + 逐字歌词（词级 LRC），右侧播放控制 |
| `music-space.png` | 音乐空间 | 主页：封面黑胶、歌词区、EQ 频响与电平表 |
| `dsp.png` | 音乐空间 · DSP | DSP 直通/信号路径弹层，显示输出模式与输出规格 |

## 采集与脱敏说明

- 截图只使用**合成测试曲库**（`fixtures/` 与自造 WAV），曲目名为通用测试数据，
  不含真实用户目录、盘符、用户名或个人文件路径。
- 界面中不含登录会话、昵称、头像或任何凭证；「发现」等在线页面均为未登录态。
- 复现方式见根目录 `README.md` 的「开发」一节；界面样式随版本可能变化，
  截图不作为像素级回归基线。

## 许可

截图内容为 Stringmoon 项目自身界面，随本仓库同许可发布。
