## 0. 结论

四块全部落地，自动化范围内 PASS（独立验证者结论）。

## 1. 用户可感知变化

- **暂停/恢复**：不再咔哒；恢复几乎瞬时（0.5ms），暂停时端点不断流（USB DAC/蓝牙底噪显著减少）。
- **切歌/拖动进度条**：都有短淡出/淡入，不再有硬切噪音。
- **音效**：设置 → 输出 → 空间音频：关 / 串音消除（耳机）/ 立体声加宽 / 虚拟环绕（有约 21ms 延迟，界面已注明）。默认关，不影响 bit-perfect。
- **过渡时长**：5–50ms 可调，默认 10ms。
- **搜索**：全局搜索新增「GD 音乐台」分组（网易云/JOOX 可用性如实显示），可播放/看歌词；详情有「相似歌曲」（Embeat，降级会标注原因）；**第三方源不提供下载**。
- **队列**：播放栏右侧队列按钮 → 抽屉；可拖拽/上下移/删除/清空/按文件夹·歌名·歌手·时长·添加顺序排序（升降序）。
- **文件夹**：曲库视图新增「文件夹」页签，按磁盘目录层级浏览，整目录播放/入队；**你的歌现在能按文件夹区分**。

## 3. 未做 / 人工项（如实）

- **真机听感未自动化**：爆音是否完全消失、蓝牙/独占端点底噪、虚拟环绕主观效果，需你戴耳机实测（自动化只能证明「无硬切、无未排空残留、曲线等功率」）。因你的安装版一直在用，本轮**没有做 loopback 录音**。
- 空间音频不含 Dolby Atmos 商业解码（不合法也不高效）；只做双耳 crossfeed/width/virtual。
- GD 音乐台是第三方聚合源：上游随时可能限流/改协议；不提供下载（合规）。Embeat 只用于相似推荐，未内嵌模型。
- Windows N 需 Media Feature Pack（引擎加载期依赖 MFPlat/MFReadWrite）。
